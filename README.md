# Python Quiz Game

Python으로 구현한 콘솔 기반 퀴즈 게임입니다.  
사용자는 메뉴를 통해 퀴즈를 풀고, 새로운 퀴즈를 추가하고, 등록된 퀴즈 목록과 최고 점수를 확인할 수 있습니다.

퀴즈 데이터와 최고 점수는 `state.json` 파일에 저장되며, 프로그램을 종료한 뒤 다시 실행해도 데이터가 유지됩니다.

---

## 프로젝트 개요

이 프로젝트는 Python 기본 문법, 객체지향 프로그래밍, 파일 입출력, 예외 처리, Git 사용 흐름을 학습하기 위해 만든 콘솔 기반 퀴즈 게임입니다.

프로그램은 터미널에서 실행되며, 사용자는 숫자 메뉴를 입력하여 원하는 기능을 선택합니다.

주요 학습 내용은 다음과 같습니다.

- 변수와 자료형 사용
- 조건문과 반복문 사용
- 함수와 메서드 분리
- 클래스와 객체 활용
- JSON 파일 저장 및 불러오기
- 사용자 입력 검증
- 예외 처리
- Git 커밋, 브랜치, 병합, push, pull, clone 실습

---

## 퀴즈 주제와 선정 이유

이 프로젝트의 기본 퀴즈 주제는 **정보처리기사/개발 입문 기초 개념**입니다.

선정 이유는 현재 정보처리기사 필기를 준비하고 있어, Python과 Git을 배우는 과정에서 관련 개념도 함께 복습하기 위해서입니다. 
소프트웨어 생명주기, 데이터베이스, 네트워크, 객체지향, SQL 등은 정보처리기사 필기와 개발 기초 학습에 모두 관련된 내용이므로 퀴즈 주제로 선정했습니다.

기본으로 포함된 퀴즈는 5개이며, 사용자가 직접 새로운 퀴즈를 추가할 수도 있습니다.

```bash
git clone https://github.com/사용자명/저장소명.git
```

## 기능 목록

### 1. 퀴즈 풀기

등록된 퀴즈를 순서대로 풀 수 있습니다.

- 문제와 4개의 선택지가 출력됩니다.
- 사용자는 정답 번호를 입력합니다.
- 정답 여부를 바로 확인할 수 있습니다.
- 모든 문제를 풀면 최종 점수가 출력됩니다.
- 기존 최고 점수보다 높은 점수를 얻으면 최고 점수가 갱신됩니다.
- 최고 점수는 `state.json`에 저장됩니다.

---

### 2. 퀴즈 추가

사용자가 직접 새로운 퀴즈를 등록할 수 있습니다.

입력하는 정보는 다음과 같습니다.

- 문제
- 선택지 4개
- 정답 번호

추가한 퀴즈는 프로그램 실행 중에만 유지되는 것이 아니라 `state.json`에 저장됩니다.  
따라서 프로그램을 종료한 뒤 다시 실행해도 추가한 퀴즈가 유지됩니다.

---

### 3. 퀴즈 목록 확인

현재 등록된 퀴즈 목록을 확인할 수 있습니다.

- 문제 번호
- 문제 내용
- 선택지
- 정답 번호

등록된 퀴즈가 없는 경우에는 안내 메시지를 출력합니다.

---

### 4. 점수 확인

현재까지 기록된 최고 점수를 확인할 수 있습니다.

퀴즈를 한 번도 풀지 않은 경우에는 기본값인 `0점`이 표시됩니다.

---

### 5. 프로그램 종료

메뉴에서 종료를 선택하면 프로그램이 종료됩니다.

또한 실행 중 `Ctrl+C` 또는 입력 스트림 종료 상황이 발생해도 프로그램이 비정상 종료되지 않도록 예외 처리를 추가했습니다.

## Quiz 클래스

`Quiz` 클래스는 개별 퀴즈 한 문제를 표현하는 클래스입니다.

하나의 퀴즈가 가져야 하는 데이터와 기능을 관리합니다.

### 속성

| 속성 | 설명 |
|---|---|
| `question` | 퀴즈 문제 |
| `choices` | 선택지 목록 |
| `answer` | 정답 번호 |

예시:

```python
Quiz(
    "데이터베이스에서 기본키의 특징으로 맞는 것은?",
    ["중복 가능", "NULL 가능", "유일성", "정렬 전용"],
    3
)
```

---

### 메서드

| 메서드 | 설명 |
|---|---|
| `__init__()` | 퀴즈 객체를 생성할 때 문제, 선택지, 정답을 초기화 |
| `display()` | 문제와 선택지를 화면에 출력 |
| `check_answer()` | 사용자가 입력한 답이 정답인지 확인 |
| `to_dict()` | Quiz 객체를 JSON 저장 가능한 dict 형태로 변환 |
| `from_dict()` | dict 데이터를 Quiz 객체로 변환 |

---

### 주요 메서드 설명

#### `display()`

퀴즈 문제와 선택지를 출력합니다.

```python
def display(self):
    print(self.question)
    for i, choice in enumerate(self.choices, start=1):
        print(f"{i}. {choice}")
```

---

#### `check_answer()`

사용자가 입력한 정답 번호와 실제 정답 번호를 비교합니다.

```python
def check_answer(self, user_answer):
    return self.answer == user_answer
```

정답이면 `True`, 오답이면 `False`를 반환합니다.

---

#### `to_dict()`

`Quiz` 객체를 JSON 파일에 저장하기 위해 딕셔너리 형태로 변환합니다.

```python
def to_dict(self):
    return {
        "question": self.question,
        "choices": self.choices,
        "answer": self.answer
    }
```

---

#### `from_dict()`

JSON 파일에서 불러온 딕셔너리 데이터를 다시 `Quiz` 객체로 변환합니다.

```python
@classmethod
def from_dict(cls, data):
    return cls(
        data["question"],
        data["choices"],
        int(data["answer"])
    )
```

## QuizGame 클래스

`QuizGame` 클래스는 퀴즈 게임 전체를 관리하는 클래스입니다.

메뉴 출력, 퀴즈 진행, 퀴즈 추가, 목록 확인, 점수 관리, 파일 저장/불러오기 등을 담당합니다.

---

### 속성

| 속성 | 설명 |
|---|---|
| `STATE_FILE` | 데이터를 저장할 JSON 파일 경로 |
| `quizzes` | Quiz 객체들이 저장된 리스트 |
| `score` | 가장 최근에 푼 퀴즈 점수 |
| `total_answered` | 가장 최근에 푼 문제 수 |
| `best_score` | 최고 점수 |

---

### 메서드

| 메서드 | 설명 |
|---|---|
| `__init__()` | 게임 실행에 필요한 기본 속성을 초기화하고 저장 데이터를 불러옴 |
| `reset_state_to_default()` | 기본 퀴즈와 초기 점수 상태로 되돌림 |
| `save_state()` | 퀴즈 목록과 점수 정보를 `state.json`에 저장 |
| `safe_save_on_exit()` | 강제 종료 상황에서 가능한 범위 내 저장 시도 |
| `load_state()` | `state.json`에서 저장된 데이터를 불러옴 |
| `run()` | 전체 프로그램 실행 루프 |
| `get_default_quizzes()` | 기본 퀴즈 데이터를 생성 |
| `show_menu()` | 메뉴 화면 출력 |
| `get_valid_number()` | 숫자 입력 검증 |
| `get_required_text()` | 빈 문자열을 허용하지 않는 문자 입력 처리 |
| `play_quiz()` | 퀴즈 풀이 기능 |
| `add_quiz()` | 퀴즈 추가 기능 |
| `show_quiz_list()` | 퀴즈 목록 출력 |
| `show_score()` | 최고 점수 출력 |

## 주요 구현 내용

### 1. 메뉴 기반 실행 흐름

프로그램을 실행하면 메뉴가 출력되고, 사용자가 번호를 선택하면 해당 기능이 실행됩니다.

```text
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 점수 확인
5. 종료
```

메뉴 선택은 `get_valid_number()` 메서드를 통해 검증합니다.

---

### 2. 공통 숫자 입력 검증

숫자 입력이 필요한 곳에서는 `get_valid_number()` 메서드를 사용합니다.

이 메서드는 다음 상황을 처리합니다.

| 상황 | 처리 |
|---|---|
| 빈 입력 | 안내 메시지 출력 후 재입력 |
| 숫자가 아닌 입력 | 안내 메시지 출력 후 재입력 |
| 허용 범위 밖 숫자 | 안내 메시지 출력 후 재입력 |

예시:

```python
choice = self.get_valid_number(
    "메뉴를 선택하세요: ",
    1,
    5
)
```

정답 입력에서도 같은 메서드를 사용합니다.

```python
user_answer = self.get_valid_number(
    "정답 번호를 입력하세요: ",
    1,
    len(quiz.choices)
)
```

---

### 3. 공통 문자열 입력 검증

퀴즈 문제나 선택지를 입력할 때 빈 입력을 막기 위해 `get_required_text()` 메서드를 사용합니다.

```python
question = self.get_required_text(
    "문제를 입력하세요: ",
    "문제는 비워둘 수 없습니다."
)
```

이를 통해 문제나 선택지가 비어 있는 상태로 저장되지 않도록 처리했습니다.

---

### 4. 퀴즈 데이터 관리

퀴즈는 `Quiz` 객체로 관리합니다.

여러 개의 퀴즈는 리스트에 저장됩니다.

```python
self.quizzes = []
```

기본 퀴즈는 `get_default_quizzes()` 메서드에서 생성합니다.

---

### 5. 점수 관리

퀴즈를 모두 풀면 맞힌 개수를 계산합니다.

```python
if quiz.check_answer(user_answer):
    score += 1
```

퀴즈 풀이가 끝나면 현재 점수와 최고 점수를 비교합니다.

```python
if score > self.best_score:
    self.best_score = score
```

최고 점수가 갱신되면 `state.json`에 저장됩니다.

### state.json 경로

`state.json` 파일은 프로젝트 루트에 저장됩니다.

```text

```

---

### state.json 역할

`state.json`은 프로그램의 데이터를 유지하기 위해 사용됩니다.

저장되는 데이터는 다음과 같습니다.

- 최근 점수

- 최고 점수

프로그램을 종료해도 `state.json`에 데이터가 남아 있기 때문에, 다시 실행했을 때 이전 데이터가 유지됩니다.

---

### state.json 스키마

현재 프로젝트에서 사용하는 데이터 구조는 다음과 같습니다.

```json
{
    "quizzes": [
        {
            "question": "Python의 창시자는?",
            "choices": ["Guido", "Linus", "Bjarne", "James"],
            "answer": 1
        }
    ],
    "score": 1,
    "total_answered": 1,
    "best_score": 1
}
```

---

### 필드 설명

| 필드 | 타입 | 설명 |
|---|---|---|
| `quizzes` | list | 퀴즈 데이터 목록 |
| `question` | str | 퀴즈 문제 |

| `answer` | int | 정답 번호 |
| `score` | int | 가장 최근 퀴즈 풀이 점수 |
| `total_answered` | int | 가장 최근에 푼 문제 수 |
| `best_score` | int | 최고 점수 |

## 파일 저장 및 불러오기

### 저장 방식

퀴즈 데이터와 점수 정보는 `save_state()` 메서드에서 저장합니다.

단순히 `state.json`을 바로 덮어쓰지 않고, 임시 파일을 먼저 만든 뒤 저장이 완료되면 기존 파일과 교체하는 방식을 사용했습니다.

저장 흐름은 다음과 같습니다.

```text
1. state.json.tmp 파일에 먼저 저장
2. 저장이 정상적으로 끝나면 state.json으로 교체
3. 저장 중 오류가 발생하면 임시 파일 삭제
4. 기존 state.json은 가능한 유지
```

이 방식을 사용한 이유는 저장 중 `Ctrl+C` 등으로 프로그램이 종료되더라도 기존 `state.json`이 깨지는 위험을 줄이기 위해서입니다.

---

### 불러오기 방식

프로그램 시작 시 `load_state()` 메서드에서 `state.json` 파일을 불러옵니다.

처리 방식은 다음과 같습니다.

| 상황 | 처리 |
|---|---|
| `state.json` 파일이 있음 | 저장된 퀴즈와 점수를 불러옴 |
| `state.json` 파일이 없음 | 기본 퀴즈 데이터로 시작하고 새 파일 생성 |
| `state.json` 파일이 손상됨 | 안내 메시지 출력 후 기본 데이터로 초기화 |
| 파일 읽기 오류 발생 | 안내 메시지 출력 후 기본 데이터로 실행 |

## 예외 처리

이 프로젝트에서는 사용자가 잘못 입력하거나 파일에 문제가 생겨도 프로그램이 갑자기 종료되지 않도록 예외 처리를 추가했습니다.

---

### 숫자 입력 예외 처리

숫자 입력이 필요한 곳에서는 다음 예외 상황을 처리합니다.

| 예외 상황 | 예시 | 처리 방식 |
|---|---|---|
| 빈 입력 | Enter | 안내 메시지 출력 후 재입력 |
| 숫자가 아닌 입력 | `abc` | 안내 메시지 출력 후 재입력 |
| 범위 밖 입력 | `0`, `9` | 허용 범위 안내 후 재입력 |

---

### 문자열 입력 예외 처리

퀴즈 문제와 선택지는 빈 값으로 저장되지 않도록 처리했습니다.

| 예외 상황 | 예시 | 처리 방식 |
|---|---|---|
| 빈 문제 입력 | Enter | 안내 메시지 출력 후 재입력 |
| 빈 선택지 입력 | Enter | 안내 메시지 출력 후 재입력 |

---

### 파일 예외 처리

`state.json` 파일을 읽거나 쓸 때 발생할 수 있는 오류를 처리합니다.

처리하는 주요 오류는 다음과 같습니다.

| 오류 | 상황 |
|---|---|
| `FileNotFoundError` | `state.json` 파일이 없는 경우 |
| `json.JSONDecodeError` | JSON 파일이 손상된 경우 |
| `KeyError` | 필요한 데이터 키가 없는 경우 |
| `TypeError` | 데이터 타입이 예상과 다른 경우 |
| `ValueError` | 숫자 변환이나 데이터 구조가 잘못된 경우 |
| `OSError` | 파일 읽기/쓰기 자체에 문제가 있는 경우 |

---

### Ctrl+C 및 EOFError 처리

프로그램 실행 중 사용자가 `Ctrl+C`를 누르거나 입력 스트림이 종료되어도 Traceback이 출력되며 비정상 종료되지 않도록 처리했습니다.

처리 방식은 다음과 같습니다.

```text
1. 종료 안내 메시지 출력
2. 가능한 범위에서 현재 데이터 저장 시도
3. 저장 중 문제가 발생해도 기존 state.json이 깨지지 않도록 처리
4. 프로그램 종료
```

---

### 사용한 주요 Git 명령어

| 명령어 | 설명 |
|---|---|
| `git init` | 현재 폴더를 Git 저장소로 초기화 |

| `git add` | 변경된 파일을 스테이징 영역에 추가 |
| `git commit` | 스테이징된 변경사항을 하나의 기록으로 저장 |
| `git push` | 로컬 커밋을 원격 저장소에 업로드 |

| `git checkout` | 브랜치 이동 또는 생성에 사용 |

| `git clone` | 원격 저장소를 로컬에 복제 |
| `git merge` | 다른 브랜치의 변경사항을 현재 브랜치에 병합 |
| `git log` | 커밋 기록 확인 |

---

### 브랜치 작업 예시

기능 개발을 위해 새 브랜치를 생성합니다.

```bash

```

또는 다음 명령어를 사용할 수도 있습니다.

```bash
git switch -c feature/play-quiz
```

작업 후 변경 파일을 스테이징하고 커밋합니다.

```bash
git add main.py
git commit -m "Feat: 퀴즈 풀이 기능 구현"
```

`main` 브랜치로 이동한 뒤 기능 브랜치를 병합합니다.

```bash
git switch main
git merge feature/play-quiz
```

원격 저장소에 업로드합니다.

```bash
git push origin main
```

## Git Clone / Pull 로그 이력

### 1. Git Clone

원격 저장소를 로컬 Desktop 경로에 복제하였다.

```bash
tjdxo9514764@c6r9s8 Desktop % git clone https://github.com/tjdxo/mission2.git
'mission2'에 복제합니다...
remote: Enumerating objects: 57, done.
remote: Counting objects: 100% (57/57), done.
remote: Compressing objects: 100% (34/34), done.
remote: Total 57 (delta 26), reused 49 (delta 18), pack-reused 0 (from 0)
오브젝트를 받는 중: 100% (57/57), 21.39 KiB | 7.13 MiB/s, 완료.
델타를 알아내는 중: 100% (26/26), 완료.
```

### 2. Clone 확인

`ls` 명령어로 `mission2` 폴더가 생성된 것을 확인하였다.

```bash
tjdxo9514764@c6r9s8 Desktop % ls
mission2                        무제 폴더
```

### 3. 프로젝트 폴더 이동

복제된 `mission2` 폴더로 이동하였다.

```bash
tjdxo9514764@c6r9s8 Desktop % cd mission2
```

### 4. Git Pull 확인

원격 저장소와 로컬 저장소가 최신 상태인지 확인하였다.

```bash
tjdxo9514764@c6r9s8 mission2 % git pull
이미 업데이트 상태입니다.
```

### 정리

- `git clone`을 통해 원격 저장소를 로컬 환경에 복제하였다.
- `ls` 명령어로 복제된 `mission2` 폴더 생성을 확인하였다.
- `cd mission2`로 프로젝트 폴더에 진입하였다.
- `git pull` 결과 이미 최신 상태임을 확인하였다.
